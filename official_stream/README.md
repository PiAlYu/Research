# Official STREAM 5.10

`stream.c` сохранён без изменений. Исходный файл получен с официального сайта:

<https://www.cs.virginia.edu/stream/FTP/Code/stream.c>

Ожидаемая версия: STREAM 5.10 от 17 января 2013 года. Исходный файл содержит
собственную лицензию John D. McCalpin, разрешающую использование и
распространение с указанными в ней правилами публикации результатов.

Файл `cache_runner.cpp` и папка `compat/` не меняют четыре официальных ядра.
Они только добавляют запуск под Windows, affinity и измерение не меньше 2 секунд.
Python пересобирает этот адаптер для каждого `N`, а затем запускает все
конфигурации ядер. Полный результат сохраняется в `results/all_results.csv`.
