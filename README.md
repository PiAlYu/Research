# STREAM: тест скорости памяти

В проекте отдельно лежат две программы:

- `my_stream/` — моя реализация на C++ и Python;
- `official_stream/` — официальный STREAM 5.10 и отдельный Python-скрипт для него;
- `run.py` — запускает все замеры обеих программ и создаёт CSV;
- `plot.py` — отдельно строит графики по готовым CSV;
- `make_presentation.py` — отдельно создаёт PDF из готовых CSV;
- `REPORT.md` — отчёт;
- `STREAM_presentation.pdf` — презентация.

Нужны Python 3, `matplotlib` и Microsoft C++ с OpenMP. Путь к
`vcvars64.bat` указан в переменной `VCVARS` в обоих Python-скриптах.

Установка библиотеки для графиков:

```powershell
py -m pip install -r requirements.txt
```

Полный запуск всех конфигураций и всех `N`:

```powershell
py run.py
```

Он занимает не меньше 96 минут: проверяются 9 конфигураций, 40 размеров и 4
операции по 2 секунды для моей и официальной реализации.

Графики и презентация запускаются отдельно:

```powershell
py plot.py
py make_presentation.py
```

Можно запускать программы отдельно:

```powershell
py my_stream/run.py
py official_stream/run.py
```

Моя программа использует три массива по 512 МиБ. Windows-версия Copy переносит
по четыре AVX2-вектора, то есть по 16 чисел `double` за шаг. Для больших массивов
используется потоковая запись. Это не даёт MSVC заменить короткий цикл частыми
вызовами `memcpy`. Официальный `stream.c` сохранён без изменений. Каждый
адаптивный замер идёт не меньше 2 секунд.

Polus использует процессоры POWER8, поэтому AVX2 там невозможен. В отдельном
`polus/stream.cpp` остаётся переносимый цикл, который оптимизирует `g++` для
POWER8.

Главные результаты полного запуска:

- `my_stream/results/all_results.csv` — все мои конфигурации и все `N`;
- `official_stream/results/all_results.csv` — все конфигурации официального STREAM;
- `cache_results.csv` в каждой папке — однопоточный срез для старого графика кэшей;
- `ram_results.csv` в каждой папке — срез всех конфигураций при максимальном `N`;
- `results/ram_comparison.csv` и `results/ram_comparison.svg` — общее сравнение.

Во время длинного теста `all_results.csv` перезаписывается после каждого
сочетания конфигурации и `N`, поэтому уже готовые строки не теряются при сбое.

График `my_stream/results/cache_ram_zoom.svg` отдельно показывает последнюю
часть однопоточного теста, где находятся L3 и RAM.

Папка `polus/` содержит отдельную версию для POWER8/Linux, LSF-файлы и подробную
инструкцию запуска через очередь суперкомпьютера. Папка `polus_official/`
содержит отдельную обвязку официального STREAM 5.10. Полная последовательность
обоих запусков находится в `POLUS_RUN.md`.

Нумерация P- и E-ядер задана в списке `PROFILES` в обоих `run.py` для
исследованного ноутбука. На другом компьютере этот список нужно изменить.
