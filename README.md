# STREAM: тест пропускной способности памяти

Минимальный проект для Intel Core i9-12900H из двух частей:

- `src/stream.cpp` — операции Copy, Scale, Add и Triad;
- `run.py` — сборка, запуск, CSV и графики.

Нужны Python 3, `matplotlib` и компилятор Microsoft C++ с OpenMP.

```powershell
py -m pip install -r requirements.txt
py run.py
```

Обычный запуск использует по 128 МиБ на каждый из трёх векторов. Полный запуск,
соответствующий параметрам отчёта, использует по 512 МиБ (1,5 ГиБ суммарно):

```powershell
py run.py --full
```

Готовые CSV находятся в `results/`. Перестроить графики без повторного теста:

```powershell
py run.py --plot-only
```

Нумерация P/E-ядер задана в начале `run.py` для исследованного ноутбука. Если
Windows изменит нумерацию логических процессоров, список `PROFILES` нужно
скорректировать.
