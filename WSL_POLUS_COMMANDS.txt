КОМАНДЫ WSL ДЛЯ POLUS
======================

Ключ: ~/.ssh/id_rsa_hpc
Сервер: edu-cmc-sqi26-11@polus.cs.msu.ru


1. МОЯ РЕАЛИЗАЦИЯ
------------------

Создать папку на Polus:

ssh -i ~/.ssh/id_rsa_hpc edu-cmc-sqi26-11@polus.cs.msu.ru "mkdir -p ~/stream-polus"

Скопировать код и LSF-файлы:

scp -i ~/.ssh/id_rsa_hpc /mnt/c/Users/aypir/source/repos/Research/polus/run.py /mnt/c/Users/aypir/source/repos/Research/polus/stream.cpp /mnt/c/Users/aypir/source/repos/Research/polus/plot.py /mnt/c/Users/aypir/source/repos/Research/polus/README.md edu-cmc-sqi26-11@polus.cs.msu.ru:~/stream-polus/
scp -i ~/.ssh/id_rsa_hpc -r /mnt/c/Users/aypir/source/repos/Research/polus/jobs edu-cmc-sqi26-11@polus.cs.msu.ru:~/stream-polus/

Войти на Polus:

ssh -i ~/.ssh/id_rsa_hpc edu-cmc-sqi26-11@polus.cs.msu.ru

Подготовить файлы:

cd ~/stream-polus
sed -i 's/\r$//' run.py stream.cpp plot.py jobs/*.sh jobs/*.lsf
mkdir -p build results logs
chmod +x jobs/*.sh

Скомпилировать через очередь:

bsub < jobs/build.lsf
bjobs
bjobs -a | head -20
ls -lh build/stream

Запустить полный тест:

bsub < jobs/all_20cores.lsf
bjobs
bjobs -a | head -20

Посмотреть ход задания, заменив JOBID на его номер:

tail -f logs/all_20c.JOBID.out

Проверить результат после состояния DONE:

wc -l results/all_results.csv
head -1 results/all_results.csv
ls -lh results

В файле all_results.csv должна быть 641 строка: заголовок и 640 измерений.

Выйти:

logout

Создать локальные папки и скачать результаты с Polus на Windows:

mkdir -p /mnt/c/Users/aypir/source/repos/Research/polus/results /mnt/c/Users/aypir/source/repos/Research/polus/logs
scp -i ~/.ssh/id_rsa_hpc 'edu-cmc-sqi26-11@polus.cs.msu.ru:~/stream-polus/results/*' /mnt/c/Users/aypir/source/repos/Research/polus/results/
scp -i ~/.ssh/id_rsa_hpc 'edu-cmc-sqi26-11@polus.cs.msu.ru:~/stream-polus/logs/*' /mnt/c/Users/aypir/source/repos/Research/polus/logs/

4. УДАЛЕНИЕ СТАРЫХ РЕЗУЛЬТАТОВ НА POLUS
----------------------------------------

Сначала проверить каталог:

cd ~
pwd
ls -ld ./stream-polus ./stream-polus-official

Удалить только старые CSV:

rm -f -- ~/stream-polus/results/all_results.csv ~/stream-polus/results/cache_results.csv ~/stream-polus/results/ram_results.csv
rm -f -- ~/stream-polus-official/results/all_results.csv ~/stream-polus-official/results/cache_results.csv ~/stream-polus-official/results/ram_results.csv

Важно: каждую команду scp лучше вставлять одной строкой.
